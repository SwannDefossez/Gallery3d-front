Projet immersif web

Galerie3D

React Three.js Node.js MongoDB

Immersion web

Une navigation libre dans un espace 3D, avec des oeuvres consultables directement depuis l'interface.

Presentation du projet

Client

  • Explorer librement une galerie 3D depuis le web
  • Decouvrir des oeuvres dans un cadre plus immersif qu'une grille de produits
  • Consulter une fiche detaillee puis preparer un achat

Artiste

  • Exposer ses creations dans un espace virtuel plus differenciant
  • Gagner en visibilite grace a une mise en scene forte
  • Mettre en valeur ses oeuvres et faciliter leur commercialisation

Problematique

Immersion

Manque d'experience

La consultation reste souvent limitee a une page, une carte et quelques medias fixes.

Valorisation

Mise en valeur limitee

Une simple liste d'oeuvres transmet difficilement la singularite ou l'univers de l'artiste.

Visibilite

Artistes peu differencies

Sans espace immersif ou personnalise, les artistes peinent a se distinguer durablement.

Web classique

Parcours trop lineaire

Le visiteur scrolle, clique, repart. Il n'y a pas de sensation de visite ni d'exploration.

Positionnement Galerie3D

Galerie immersive

Le visiteur se deplace dans une salle 3D au lieu de faire defiler un simple catalogue.

Parcours continu

La visite, la consultation d'une fiche et l'ajout au panier restent dans un meme univers.

Valeur pour l'artiste

La mise en scene renforce l'identite de l'oeuvre et differencie mieux le travail de l'artiste.

Mise en avant hebdomadaire

Le roulement des artistes chaque semaine permet de renouveler la galerie et d'offrir a chacun un temps de visibilite dedie.

MCD simplifie

Entite Utilisateur

id, nom, email, mot de passe, role

Entite Artiste

bio, portfolio, photo, utilisateur_id

Entite Oeuvre

titre, description, prix, media, artiste_id

Entite Galerie / Salle

nom, theme, organisation, liste d'oeuvres

Entite Panier

utilisateur_id, lignes, total, statut

Entite Commande

date, total, client_id, statut

Entite LigneCommande

commande_id, oeuvre_id, quantite, prix

Utilisateur 1..1 -> 0..1 Artiste

Un utilisateur peut disposer d'un profil artiste.

Artiste 1..N -> Oeuvre

Un artiste publie plusieurs oeuvres.

Galerie 1..N -> Oeuvre

Une salle expose plusieurs oeuvres selon une scenographie choisie.

Utilisateur 1..1 -> Panier

Le panier sert d'intermediaire entre la visite et la commande.

Commande 1..N -> LigneCommande

Une commande contient une ou plusieurs lignes.

LigneCommande N..1 -> Oeuvre

Chaque ligne reference l'oeuvre achetee et le prix associe.

UML - cas d'usage

Use case Explorer la galerie

Le visiteur entre dans l'espace 3D et construit librement son parcours.

Use case Consulter une oeuvre

Le visiteur clique sur une oeuvre et ouvre sa fiche detaillee.

Use case Ajouter au panier

Le client selectionne une oeuvre et prepare son achat.

Use case Passer commande

Le panier valide les selections puis cree une commande.

Use case Publier / gerer une oeuvre

L'artiste ajoute, modifie ou retire une oeuvre de son espace.

Use case Administrer la plateforme

L'admin supervise contenus, utilisateurs et commandes.

Visiteur

Client

Artiste

Admin

Supervise les contenus, les comptes et la coherence globale de la plateforme.

Architecture cible

Navigateur

Point d'entree utilisateur pour l'exploration et les interactions.

Frontend React + Three.js

Affiche la galerie 3D, la fiche oeuvre, le panier et l'interface.

API Node / Express

Expose auth, gestion d'oeuvres, commandes et fonctions d'administration.

MongoDB

Stocke utilisateurs, artistes, oeuvres, paniers et commandes.

Branche secondaire Assets GLB / images

Modeles, textures et previews charges dans l'interface pour enrichir l'experience visuelle.

Branche secondaire Authentification

Gestion de session et de roles selon visiteur, client, artiste ou admin.

Branche secondaire Espace admin / artiste

Back-office pour publier des oeuvres, moderer les contenus et suivre l'activite.
