Experience 3D interactive

Gallery3D

Une application web qui transforme le navigateur en espace d'exposition immersif, fluide et accessible.

Concept & Realisation Technique

Architecture

Frontend

Une scene 3D rapide, lisible et reactive

  • Three.js + React : rendu temps reel et navigation naturelle dans la galerie virtuelle.
  • Performance : scene optimisee pour conserver une exploration fluide meme avec des textures lourdes.
  • Accessibilite web : aucun client a installer, un simple lien suffit.

Infrastructure

Backend

API fiable et donnees evolutives

  • Node.js : service rapide pour la gestion des flux entre client et base.
  • Prisma : couche ORM propre pour manipuler les donnees en securite.
  • MongoDB : structure flexible pour stocker les oeuvres et leurs metadonnees.
